# Download Sticker Transfer for Android

## [⬇ Download the latest APK](https://github.com/Oly132/sticker-transfer/releases/latest/download/StickerTransfer.apk)

**Use this link on the phone where you want to install the app.** No GitHub account, computer or payment is needed. The app has no ads.

The file you want is **StickerTransfer.apk**. You do **not** need either of GitHub's **Source code** downloads or **SHA256SUMS.txt**; those are for developers or optional file verification.

1. Tap the download link above. Your browser may ask whether to keep/download an APK. Check that the page is this project's GitHub release, then confirm if you want to install it.
2. Tap **Open** when the download finishes, then **Install**. If the download closes, open **My Files/Files → Downloads → StickerTransfer.apk**.
3. Open **Sticker Sync** and follow the [simple setup instructions](INSTALL.md).

Requires Android 8+ and a 64-bit ARM phone. The experimental WhatsApp → TikTok feature requires Android 10+. Not for iPhone or iPad.

Already have Sticker Sync? Install the new APK over it and choose **Update**. **Do not uninstall first.**
